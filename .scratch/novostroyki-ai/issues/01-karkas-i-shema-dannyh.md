# 01 — Каркас проекта, база данных, запуск одной командой

**What to build:** С чистого клона репозитория человек выполняет одну команду и получает работающий сервер с поднятой базой данных и применёнными миграциями. Открывает адрес в браузере — видит, что сервис жив. Это фундамент, на который встают все остальные тикеты.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

## Контекст

Спека: `docs/SPEC.md`, разделы «Общая архитектура» и «Схема данных».

Монорепозиторий с тремя пакетами: `server` (Fastify + TypeScript), `admin` (React + Vite), `widget` (Preact + Vite). В этом тикете `admin` и `widget` создаются как минимальные заглушки — наполняются в своих тикетах.

Путь к каталогу проекта содержит пробел и кириллицу. Имя compose-проекта задать явно (`name: novostroyki-ai`), иначе Docker Compose ругается на недопустимое имя.

## Acceptance criteria

- [ ] `docker compose up` поднимает PostgreSQL и приложение, миграции применяются автоматически при старте
- [ ] `GET /api/health` отвечает `{ status: "ok", db: "ok" }` с реальной проверкой соединения с БД
- [ ] Prisma-схема содержит все модели из спеки: `Project`, `Feed`, `Apartment`, `KnowledgeDoc`, `KnowledgeChunk`, `Conversation`, `Message`, `Lead`, `Setting`
- [ ] У `KnowledgeChunk` есть колонка `tsv` типа `tsvector` с GIN-индексом, расширения `pg_trgm` и `unaccent` включены миграцией
- [ ] Уникальный индекс на `Apartment(feedId, externalId)`
- [ ] `Setting` умеет читаться и писаться через сервис настроек, значения по умолчанию засеиваются при первом старте
- [ ] `npm test` запускается и проходит; есть тест на `/api/health` и тест сервиса настроек против реальной тестовой БД
- [ ] `npm run dev` поднимает сервер с hot reload без Docker (при запущенном отдельно Postgres)
- [ ] `.env.example` содержит все переменные с комментариями на русском
- [ ] Пакеты `admin` и `widget` создаются с рабочим билдом-заглушкой; сервер отдаёт статику админки на `/admin` и файл виджета на `/widget.js`
- [ ] README описывает запуск на русском языке, без жаргона
