# 03 — Автообновление фидов по расписанию и вручную

**What to build:** Фиды обновляются сами, без участия человека, поэтому ассистент не предлагает проданные квартиры по старым ценам. Любой фид можно обновить вручную немедленно. По каждому фиду видно: когда обновлялся, сколько загрузилось, была ли ошибка и какая.

**Blocked by:** 02

**Status:** ready-for-agent

## Контекст

Спека: `docs/SPEC.md`, раздел «Синхронизация фидов». Планировщик — `node-cron` внутри процесса приложения, расписание берётся из настроек, по умолчанию каждые 3 часа.

## Acceptance criteria

- [ ] Планировщик стартует вместе с приложением и обновляет все активные фиды по расписанию из настроек
- [ ] `POST /api/admin/feeds/:id/sync` запускает обновление одного фида немедленно и возвращает результат
- [ ] Два одновременных запуска одного фида не пересекаются — второй получает отказ «уже выполняется»
- [ ] После каждого запуска у фида обновляются `lastRunAt`, `lastStatus`, `lastCount`, `lastError`
- [ ] Неактивные фиды (`isActive = false`) пропускаются планировщиком
- [ ] Падение одного фида не останавливает обновление остальных
- [ ] Изменение расписания в настройках перезапускает планировщик без перезапуска приложения
- [ ] CRUD-эндпоинты фидов: создание, чтение списка, изменение, удаление
- [ ] Тесты: расписание читается из настроек, ручной запуск возвращает результат, защита от параллельного запуска, ошибка одного фида не влияет на другие
