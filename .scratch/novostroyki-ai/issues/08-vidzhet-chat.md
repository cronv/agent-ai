# 08 — Виджет на сайте: чат и карточки квартир

**What to build:** На сайт добавляется одна строчка `<script>` — в правом нижнем углу появляется кнопка. По клику открывается чат в светлом минималистичном стиле. Посетитель пишет запрос, ответ печатается на глазах, подобранные квартиры показываются карточками с планировкой, ценой, площадью, этажом и ссылкой. Всё работает с телефона и не ломает вёрстку сайта.

**Blocked by:** 06

**Status:** ready-for-agent

## Контекст

Спека: `docs/SPEC.md`, раздел «Виджет».

Preact + Vite, сборка в один самодостаточный `widget.js`. Монтирование в Shadow DOM — стили сайта не протекают внутрь, стили виджета не протекают наружу.

**Визуальный стиль — светлый минимализм.** Белый фон, много воздуха, один акцентный цвет из настроек, крупная читаемая типографика, мягкие тени, скруглённые углы. Это витрина дорогого товара — виджет должен выглядеть дорого. Обязательно прочитать навык `ui-ux-pro-max` перед версткой.

## Acceptance criteria

- [ ] Подключение одной строчкой `<script src="…/widget.js" defer></script>`, без правок вёрстки сайта
- [ ] Всё рендерится в Shadow DOM; стили страницы-хозяина не влияют на виджет и наоборот
- [ ] Кнопка в правом нижнем углу, открытие и сворачивание чата с плавной анимацией
- [ ] Приветствие и примеры вопросов подтягиваются из настроек; клик по примеру отправляет его как сообщение
- [ ] Ответ приходит потоком и печатается по мере генерации; виден индикатор «печатает»
- [ ] Карточка квартиры: превью планировки, комнатность, площадь, этаж из общего, ЖК, цена, кнопка перехода на карточку
- [ ] Планировка открывается крупно по клику
- [ ] Несколько квартир показываются лентой с горизонтальной прокруткой, не растягивая окно чата
- [ ] Битая или отсутствующая планировка заменяется аккуратной заглушкой, а не сломанной картинкой
- [ ] Акцентный цвет и название берутся из настроек и применяются без пересборки
- [ ] История подгружается при возврате на сайт по `sessionId` из `localStorage`
- [ ] На мобильном чат раскрывается на весь экран, поле ввода не перекрывается клавиатурой
- [ ] Ошибка сети или сервера показывается человеческим текстом с кнопкой «Повторить», а не пустым экраном
- [ ] Размер собранного бандла — в пределах 100 КБ в gzip
- [ ] Есть демо-страница, на которой виджет можно посмотреть локально
