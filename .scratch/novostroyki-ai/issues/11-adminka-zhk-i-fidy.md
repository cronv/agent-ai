# 11 — Админка: жилые комплексы и фиды

**What to build:** В админке человек добавляет фид застройщика по ссылке, выбирает формат и нажимает «Обновить сейчас» — видит, сколько квартир загрузилось, или текст ошибки, если фид битый. В разделе ЖК он дополняет карточки тем, чего нет в фиде: район, метро, срок сдачи, отделка, описание. Ненужный ЖК выключается одним переключателем — ассистент перестаёт его предлагать.

**Blocked by:** 03, 10

**Status:** ready-for-agent

## Контекст

Спека: `docs/SPEC.md`, разделы «Синхронизация фидов» и «Схема данных».

## Acceptance criteria

- [ ] Список фидов: название, ссылка, формат, расписание, последнее обновление, число загруженных квартир, статус
- [ ] Добавление и редактирование фида: название, ссылка, формат (`yandex` / `cian` / `custom`), активность
- [ ] Для формата `custom` — редактор соответствия полей: путь в XML → поле квартиры, с подсказками
- [ ] Кнопка «Обновить сейчас» с индикатором выполнения и результатом: добавлено, обновлено, деактивировано, пропущено
- [ ] Ошибка фида показывается полным текстом, а не «что-то пошло не так»
- [ ] Удаление фида спрашивает подтверждение и говорит, сколько квартир это затронет
- [ ] Список ЖК: название, застройщик, район, число активных квартир, диапазон цен, переключатель активности
- [ ] Редактирование ЖК: название, застройщик, район, метро, время до метро, адрес, срок сдачи, отделка, описание, ссылка, картинка
- [ ] Выключенный ЖК исчезает из выдачи ассистента — проверено тестом
- [ ] Карточка ЖК показывает список его квартир с фильтрами по комнатности и цене
- [ ] Тесты: CRUD фида, ручной запуск синхронизации через интерфейсный эндпоинт, редактирование ЖК, выключенный ЖК не попадает в `search_apartments`
