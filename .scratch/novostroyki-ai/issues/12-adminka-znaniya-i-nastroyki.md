# 12 — Админка: база знаний и настройки

**What to build:** Человек перетаскивает PDF-презентацию застройщика в окно браузера, выбирает, к какому ЖК она относится — и ассистент начинает отвечать по ней. В настройках он меняет характер ассистента, приветствие, цвет и название виджета, вставляет ключ доступа к модели и копирует готовую строчку для установки на сайт. Всё без программиста.

**Blocked by:** 04, 10

**Status:** ready-for-agent

## Контекст

Спека: `docs/SPEC.md`, разделы «Поиск по базе знаний» и «Схема данных» (модель `Setting`).

## Acceptance criteria

- [ ] Загрузка файлов перетаскиванием и по кнопке, несколько файлов сразу, с индикатором обработки
- [ ] При загрузке выбирается ЖК или «общий документ» без привязки
- [ ] Список документов: имя, ЖК, размер, число фрагментов, дата, статус обработки
- [ ] Документ со статусом ошибки показывает причину текстом
- [ ] Удаление документа с подтверждением; фрагменты исчезают из выдачи
- [ ] Поле проверки поиска: вводишь вопрос — видишь, какие фрагменты найдёт ассистент и из какого документа
- [ ] Настройки: системный промпт (многострочное поле с подсказкой, что это), приветствие, примеры вопросов, порог запроса контакта
- [ ] Настройки внешнего вида: название виджета, акцентный цвет с выбором цвета, ссылка на политику обработки персональных данных
- [ ] Настройки интеграций: ключ Anthropic (вводится, отображается замаскированным), адрес вебхука для лидов, расписание обновления фидов
- [ ] Кнопка проверки ключа Anthropic — делает пробный запрос и говорит, работает ли
- [ ] Блок «Установка на сайт» с готовой строчкой `<script>` и кнопкой копирования
- [ ] Изменение настроек применяется без перезапуска приложения
- [ ] Тесты: загрузка и обработка файла, привязка к ЖК, удаление, чтение и запись настроек, маскирование ключа при чтении
