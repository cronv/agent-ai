# 13 — Админка: переписки и лиды

**What to build:** Менеджер открывает список лидов, видит имя и телефон, одним кликом проваливается в переписку и читает, что человек спрашивал и какие квартиры ему показали. Звонит подготовленным. Ставит статус, чтобы коллега не позвонил повторно. Выгружает список в CSV, чтобы отдать в отдел продаж.

**Blocked by:** 06, 07, 10

**Status:** ready-for-agent

## Контекст

Спека: `docs/SPEC.md`, разделы «Схема данных» и «Запрос контакта».

## Acceptance criteria

- [ ] Список переписок: дата, первое сообщение пользователя, число сообщений, есть ли лид, страница входа
- [ ] Поиск по перепискам: по тексту сообщений, по имени и телефону лида
- [ ] Фильтры: по датам, только с лидом, только без лида
- [ ] Просмотр переписки целиком в виде диалога, с сохранением порядка и ролей
- [ ] В переписке видно, какие квартиры показывал ассистент — карточками, а не сырым JSON
- [ ] В переписке видно, какую модель использовал каждый ответ и сколько токенов потрачено
- [ ] Список лидов: имя, телефон, дата, статус, страница и UTM-метка, ссылка на переписку
- [ ] Смена статуса лида прямо из списка, без перехода в карточку
- [ ] Фильтры лидов по статусу и датам, поиск по имени и телефону
- [ ] Кнопка выгрузки в CSV с учётом текущих фильтров, файл открывается в Excel без проблем с кириллицей
- [ ] Телефон кликабелен — нажатие открывает звонок
- [ ] Если отправка лида в вебхук провалилась, это видно в карточке лида с текстом ошибки
- [ ] Постраничная навигация в обоих списках, работает на нескольких тысячах записей
- [ ] Тесты: список и фильтры переписок, поиск по тексту, просмотр диалога, фильтры лидов, смена статуса, выгрузка CSV с кириллицей
