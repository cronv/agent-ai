# 14 — Демо-данные, инструкция и проверка всей сборки

**What to build:** Человек, который никогда не видел этот проект, выполняет одну команду и через пару минут видит работающего ассистента с квартирами, планировками и базой знаний — до того, как получил реальные фиды и ключи. Инструкция написана человеческим языком: как запустить, куда вставить ключ, как поставить на сайт, как выложить на сервер.

**Blocked by:** 01, 02, 03, 04, 05, 06, 07, 08, 09, 10, 11, 12, 13

**Status:** ready-for-agent

## Контекст

Спека: `docs/SPEC.md`, раздел «Further Notes» — список того, что пользователь должен вставить сам.

Пользователь — не программист. Инструкция пишется на русском, без жаргона, по шагам.

## Acceptance criteria

- [ ] Демо-фид: XML на 30 квартир в 4 вымышленных ЖК разных районов, с планировками-заглушками; лежит в проекте и раздаётся локально, чтобы импорт работал без интернета
- [ ] Демо-документ базы знаний: условия ипотеки и сроки сдачи по демо-ЖК
- [ ] Команда засева демо-данных: создаёт фид, импортирует квартиры, загружает документ, создаёт настройки по умолчанию
- [ ] С пустым ключом Anthropic приложение поднимается и админка работает; чат честно говорит, что ключ не задан, и не падает
- [ ] Демо-страница с виджетом доступна локально и показывает его на фоне реалистичной вёрстки сайта
- [ ] README на русском: что это, как запустить, как вставить ключ, как добавить фид, как загрузить базу знаний, как поставить на сайт, как выложить на сервер
- [ ] Отдельный раздел README «Что нужно от вас» — все PLACEHOLDER из спеки списком
- [ ] Весь набор тестов проходит на чистом клоне
- [ ] `docker compose up` на чистом клоне поднимает всё без ручных шагов
- [ ] Сборка виджета и админки проходит без ошибок и предупреждений TypeScript
